# 测试用的固定样例图

## 这里为什么**有**图，而 `scripts/ocr-bench/samples/` 里**没有**

`scripts/ocr-bench/samples/` 里的 20 张基准图**故意不提交** ——
它们用**确定性随机种子**现场生成，**不提交**是为了避免
「换台机器字体不同，渲染出来就不一样」。

但**基准**和**测试**要的东西不一样：

| | 基准（`ocr-bench`） | 测试（`test-ai-assist-honesty`） |
|---|---|---|
| 要几张图 | **20 张**（4 档 × 5） | **1 张** |
| 跟 `truth.json` 比对吗 | **是** —— 必须逐字一致 | **否** —— 只当「一张能读的图」 |
| 对字体敏感吗 | **是** | **否** |
| 谁生成 | `make_samples.py`（要 numpy + Pillow + **中文字体**） | **提交进仓库** |

> ⭐ **测试不该依赖「环境里恰好有 Python、恰好有字体、恰好跑过一次生成脚本」。**
> 那样的话，**换台机器（或换个 CI 镜像）测试就静默地什么都不测了** ——
> 而「**0 条断言 = 通过**」是最隐蔽的一种失败。

## 这张图是什么

`ocr-math.jpg` —— 小学三年级的**长方形面积/周长**应用题，
由 `make_samples.py` 生成，**已提交**，所以：

- **任何机器上跑测试，结果都一样**
- **CI 不需要装 Python、不需要中文字体**
- 和基准的 20 张**完全无关**（那是另一套，各管各的）

## 如果你想换一张

```bash
python3 scripts/ocr-bench/make_samples.py --out /tmp/ocrtest
cp /tmp/ocrtest/real/math.jpg scripts/test-fixtures/ocr-math.jpg
```

⚠️ **换了之后**：基准的 `truth.json` **不用改**（它管的是基准那 20 张），
但**这张图的文字内容会变** —— 如果某个断言依赖图里的具体数字，记得一起改。
